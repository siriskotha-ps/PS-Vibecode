# Prototype (v3): The Build That Tests the Hypothesis

> Module 2 · Validation. The prototype is a hypothesis test, not a demo.

## Link

https://clear-action-dash.lovable.app

## What it tests

_Tie it back to the validation brief: which assumption does this prototype put in front of a user?_

Users will find a prioritized insight with a recommended next action more useful than exploring multiple charts themselves.

## Context injected (no placeholders)

- **Real user quotes on screen:** ““It tells me *what* happened but never *what to do about it*. I still export to a spreadsheet to think.” / “I open it, see twelve charts, and have no idea which one I'm supposed to act on. So I close it."
- **Domain metrics on screen:** 60% Bounce rate: sessions under 15s with no interaction. / 12 Charts on the default landing view. / 1.3Avg. weekly sessions / active user.
